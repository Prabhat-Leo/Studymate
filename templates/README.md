# StudyMate AI Frontend

Flow: **Landing Page → Login → Separate ChatGPT-style AI Assistant**

Files:
- `index.html` — product landing page
- `login.html` — frontend-only login
- `chat.html` — separate AI chat workspace
- `style.css` — shared responsive dark/purple theme
- `chat.js` — chat UI interactions

The login, AI responses, PDF processing, saved chats, quizzes and flashcards are frontend demos. Connect them to your backend/API next.
